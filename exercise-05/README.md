# Exercise 05 – Inspect Staged and Unstaged Edits

## Objective

Modify a file, stage the changes, make further modifications, and inspect the differences between the working directory, staging area, and last commit.

## Commands Used

```bash
git add README.md
git diff
git diff --staged
git diff HEAD
git add README.md
git commit -m "Exercise 05: Inspect staged and unstaged edits"
```
