# Exercise 02 – Create a Repository

## Objective

Initialize a Git repository on the main branch, create a README file containing student details and project information, stage and commit the file, and verify the repository status and commit history.

## Commands Used

```bash
git init -b main
git status
git add README.md
git commit -m "Exercise 02: Create repository"
git log --oneline
```
