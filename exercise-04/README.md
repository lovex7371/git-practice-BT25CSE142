# Exercise 04 – Stage Selected Files

## Objective

Create two files, stage and commit only one file while leaving the other untracked, and then stage and commit the remaining file.

## Commands Used

```bash
git status
git add file1.txt
git status
git commit -m "Exercise 04: Add first file"
git add file2.txt
git commit -m "Exercise 04: Add second file"
```
